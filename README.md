# Runara Docs

Runara engineering docs, published as a static site on GitHub Pages:

**https://runaraai.github.io/runara-docs/**

The landing page links to three places:

- **Artifacts** — published briefs, reports and references (`artifacts.html`)
- **Runara GDrive Docs** — the shared Google Drive folder of Runara documents
- **Meeting Notes** — team meeting notes (`meeting-notes.html`)

Pushing to `master` deploys automatically. To add or edit a page, see [AGENTS.md](AGENTS.md).
